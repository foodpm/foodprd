# 元素必写规则清单 / 通用文案库 / 自检清单

原型只画"长什么样"，PRD 要补"什么情况下长什么样"。下表按元素类型列出**必须写到**的规则点，逐项核对可避免绝大多数需求遗漏。

## 一、按元素类型核对

### 文本类（页面标题、名称、昵称、地址、简介）
- 取值来源：后台设置的「X」字段 / 用户填写的「X」/ 接口返回
- 超长处理：`如果超过固定区域，末尾用“…”表示`（多行则写"最多展示 N 行，超出末尾用“…”表示"）
- 是否需要展示全部文字（长文案区域要显式写"需要展示后台设置的全部文字"）
- 空值兜底：字段为空时展示什么（隐藏该行 / 展示默认文案）

### 图片类（头图、banner、轮播、介绍图、头像）
- 取值来源与**排序规则**（按上传顺序由前往后）
- 是否自动轮播、间隔秒数、是否支持手动切换
- 指示器样式、是否循环
- 非标准比例的适配：`根据该区域的尺寸进行调整，正方形可以全部展示，非正方形也全部展示，其余部分留白处理`
- 视频取封面：`如果是视频则截取画面第一帧`
- 加载失败/未上传时的占位

### 数据指标类（人数、票数、浏览量、销量、金额）
- 统计口径定义（pv 含不含重复访问、含不含游客）
- **删除后是否回退**：报名数/票数需同步减少；pv 类不回退
- 数字格式化：`超过 9999 则单位展示“w”，展示 1 位小数，第二位小数直接舍弃不进位；超过 9999.9w 展示为 9999.9w+`
- 是否需要精确展示（排行榜票数"数字要具体展示出来"，不做缩写）
- 0 值展示

### 倒计时 / 时间提示
- 分状态：未开始算到开始时间，进行中算到结束时间，已结束展示固定文案
- 展示粒度：天、小时、分钟、秒
- `如果数字是个位数需要补零展示`
- 倒计时归零瞬间的状态切换（是否需要自动刷新页面）

### 搜索
- 支持的关键词类型（编号 / 姓名 / 手机号）
- 输入后展示「删除」按钮，点击删除或手动清空恢复未输入状态
- 空关键词点击搜索的 toast 原文
- 结果展示在哪个 tab / 区域、结果排序要求、结果项的信息与交互是否复用列表
- 无结果文案原文
- 是否支持模糊匹配、是否区分大小写（待确认可标注）

### tab
- 默认选中哪个 tab
- 切换是否保留各 tab 的滚动位置与分页状态
- 各 tab 内容分别成一个二级条目

### 列表 / 卡片流
- 每个字段逐一列出（编号、预览、名称、数值、按钮）
- **排序规则**含并列时的次级因子（相同票数按最后一票时间早者靠前；无投票按报名时间早者靠前）
- 各状态下按钮的显隐（见状态矩阵）
- 整卡可点区域：`点击预览区域、姓名区域、票数区域，均跳转 X 页`
- 分页粒度（卡片流常见每 6 个，列表常见每 10 条）
- 到底提示文案
- 空状态：文案 + 空状态里的引导按钮及其等效行为

### 排行榜
- 排名计算规则（同上）、是否展示全部排名
- 头像来源（用户微信头像）
- 未开始但已有数据时是否展示榜单（默认展示，仅隐藏操作按钮）
- 多个空/未开始文案冲突时的**优先级**

### 底部悬浮 bar / 主 CTA
- 按钮在各状态下的文案与显隐（我要报名 / 已报名 / 活动已结束）
- 前置校验链与**优先级顺序**：`登录>判断会员等级>触发订阅消息>进入报名页`
- 不满足条件的拦截方式：弹窗还是 toast，文案原文，弹窗按钮的去向
- 已结束态是否可点（`点击无交互`）

### 弹窗
- 触发时机（进入哪个页面、获得奖励后）
- 频控：只弹 1 次 / 每天 1 次 / 每次进入都弹
- 文案中的变量替换说明（`弹窗文案「」中的内容展示活动名称`）
- 按钮去向（跳转对应明细页）
- **弹窗优先级与冲突处理**：谁先弹、被挤掉的弹窗何时补弹、多个同类弹窗的排序与层级

### 页面级状态
- 未开始 / 进行中 / 已结束
- 空状态、被删除、已下架、网络异常、加载中
- 未登录 / 游客可见范围
- 权限不足

### 分享
- 分享渠道、分享卡片标题与图片取值、分享后回流页面
- 已有组件文档时写「详见分享组件页」

### 订阅消息 / 通知
- 触发节点、使用的模板（`需要新增一个中奖通知模版，原有的不适用`）
- 是否支持多次订阅

## 二、通用文案库（直接复用，保持一致性）

| 场景 | 文案 |
|---|---|
| 列表到底 | “已经到底啦～” |
| 搜索无结果 | “暂无搜索结果” |
| 活动结束 | “活动已结束” |
| 未开始-列表 | “活动开始后可进行投票” |
| 未开始-排行榜 | “活动暂未开始，暂无排行” |
| 无内容 | “暂无参赛作品” |
| 搜索空关键词 toast | 请输入编号或者姓名 |
| 会员等级不足 toast | 非常抱歉，该活动仅限 xx、yy 会员参与 |

## 三、状态矩阵模板

不确定某元素在某状态下的表现时，先填这张表，再逐格写进 PRD。

| 元素 | 未开始 | 进行中 | 已结束 | 空状态 |
|---|---|---|---|---|
| 主 CTA | 我要报名 | 我要报名 / 已报名 | 活动已结束（不可点） | 立即报名 |
| 列表操作按钮 | 提醒我 + 提示文案 | 拉票 / 投票 | 查看详情 | — |
| 倒计时 | 距开始 | 距结束 | 活动已结束 | — |

## 四、交付前自检清单

- [ ] 编号层级正确：一、/ 1、/（1）/ ① / •，无 Markdown 自动编号
- [ ] 模块顺序与原型自上而下一致
- [ ] 三态（未开始/进行中/已结束）每个交互元素都交代了显隐
- [ ] 所有文本字段写了超长截断规则
- [ ] 所有数字写了格式化与极值规则、时间写了补零
- [ ] 所有列表写了排序规则（含并列次级因子）、分页粒度、到底文案
- [ ] 所有列表写了空状态文案 + 空状态按钮行为
- [ ] 数据指标写了统计口径与删除后是否回退
- [ ] 所有跳转写清目标页面
- [ ] 所有 toast / 弹窗给出文案原文
- [ ] 多重校验给出了优先级顺序
- [ ] 弹窗给出触发时机、频控、优先级冲突处理
- [ ] 页面异常态（被删除、网络异常）有交代
- [ ] 推断项已标注（待确认），无空缺、无 TBD 占位段
